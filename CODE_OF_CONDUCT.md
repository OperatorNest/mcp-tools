# Code of conduct

Everyone participating in this project should be able to contribute without harassment. Treat people with respect, discuss technical disagreements on their merits, and accept corrections without personal attacks.

Harassment, discriminatory language, threats, sexual attention, and publishing another person's private information are unacceptable. These rules apply to repository discussions, issues, pull requests and other project spaces, including conduct while representing the project.

Report incidents privately to operatornest+conduct@gmail.com. Include the relevant context and links when available. Maintainers will review reports privately, protect the reporter's identity where possible, and decide on a response. Responses may include removing content, requesting a correction, or restricting participation. Maintainers are subject to the same rules.
